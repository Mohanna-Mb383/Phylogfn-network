NUMERICAL-STABILITY NOTE
------------------------
During late training, non-finite gradients were observed.

A numerical safety guard skipped optimizer updates containing NaN/Inf
gradients so that finite model parameters were not corrupted.

The run was resumed from a finite checkpoint after an earlier NaN
failure. The RNG state was not restored bit-for-bit.

The final checkpoint was checked and contains no NaN/Inf tensors.

Because non-finite optimizer updates occurred, this run should currently
be treated as a completed KNN diagnostic experiment rather than a fully
clean causal comparison against the no-KNN baseline.

Also, the final Pearson correlation was relatively low, so convergence
quality requires further investigation.
